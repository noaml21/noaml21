# Noam Levi

Computer Science student at Bar-Ilan University, interested in systems, security, algorithms, machine learning, and software engineering.

I enjoy turning technical concepts into working, tested projects, with an emphasis on understanding the underlying design and trade-offs.

## Featured Projects

### [AgentGuard](https://github.com/noaml21/agentguard)
Runtime guardrails for AI coding agents, with command policies, workspace protection, pre-change snapshots, concurrency-safe rate limiting, structured audit logging, and automated CI testing.

### [Linux Concurrency & IPC](https://github.com/noaml21/linux-concurrency-ipc)
C/Linux benchmarking suite exploring threads, mutexes, System V semaphores, pipes, FIFOs, shared memory, and bounded-buffer synchronization.

### [ML From Scratch](https://github.com/noaml21/ml-from-scratch)
Core machine-learning algorithms implemented from scratch with Python and NumPy to connect the underlying mathematics with working implementations.

### [Better Wolt](https://github.com/noaml21/better-wolt)
Full-stack food-delivery application built as a team project with React, React Native, Node.js, MongoDB, TypeScript, and Docker.
